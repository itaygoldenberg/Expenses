# Milestone 4 — דו"חות וגרפים: תוכנית בנייה

> מקורות: `MILESTONES.md` (Milestone 4), `PRD.md` (4.5, 3.ב "צפייה בדו"חות", Edge Cases), `ARCHITECTURE.md` (טבלת הטכנולוגיות: Chart.js + react-chartjs-2; 2.5 "גרפים"), `DESIGN.md` (1.3 דף הדו"חות, 2.1, 2.3 "גרפים"), `wireframes-desktop.png`, `wireframes-mobile.png`, `mockups-desktop.png`, `mockups-mobile.png`, `style-guide.png`.
> נקודת פתיחה: `useExpenses()` (טעינת כל ההוצאות עם מצבי טעינה/שגיאה), `shared/money.ts` (אגורות), דף "דו"חות" שמציג כרגע רק כותרת.

## 1. מטרה ותחום

**בסוף ה-Milestone:** בדף "דו"חות" יש בחירת **מדד** ("סכום בשקלים" / "מספר הוצאות"), גרף **Pie לפי קטגוריות** וגרף **עמודות לפי שנים או חודשים** (עם בחירת שנה בתצוגה החודשית). שני הגרפים מבוססים תמיד על **כל** ההוצאות השמורות.

**מחוץ לתחום:** אזור "ייצוא הוצאות" (CSV/PDF ופילטרי ייצוא) — Milestone 5. כרטיס "סה"כ הוצאות" שמופיע ב-Mockup — DESIGN 1.3 קובע שהוא המחשה בלבד, ולכן **לא** נבנה. אין שינוי ב-API, אין Migration, אין נגיעה ב-Production.

## 2. חישובים (פונקציות טהורות, באגורות שלמות)

קובץ `src/features/reports/aggregate.ts`:
- `byCategory(expenses, metric)` → `[{ category, value }]` רק לקטגוריות שיש בהן הוצאות, ממוין מהגדול לקטן (במקרה של שוויון — לפי סדר הקטגוריות ב-PRD).
- `byYear(expenses, metric)` → `[{ year, value }]` מהשנה הישנה לחדשה, **כולל שנים ריקות באמצע** (ערך 0), כדי שהציר יהיה רציף ולא מטעה.
- `byMonth(expenses, year, metric)` → 12 ערכים (ינואר–דצמבר) לשנה שנבחרה, חודש בלי הוצאות = 0.
- `metric = 'amount'`: סכום ב**אגורות שלמות** (בלי חיבור של מספרים עשרוניים), והמרה לשקלים רק לתצוגה. `metric = 'count'`: מספר הוצאות.
- הפורמט בתצוגה: `₪ 1,249.90` לסכום, מספר שלם לכמות.

## 3. ממשק

### 3.1 מבנה הדף (לפי Wireframe ו-Mockup)
- כותרת **"דו"חות וניתוח הוצאות"** עם אייקון גרף.
- **"מדד"**: תיבת בחירה עם "סכום בשקלים" (ברירת מחדל) ו"מספר הוצאות". הבחירה משותפת לשני הגרפים.
- שני כרטיסים: **"הוצאות לפי קטגוריות"** ו-**"הוצאות לפי שנים / חודשים"** — זה לצד זה במחשב, זה מתחת לזה בטלפון, בגודל קריא (גובה גרף של כ-260px לפחות גם בטלפון).

### 3.2 Pie — "הוצאות לפי קטגוריות"
- עוגה רב-צבעית + **מקרא HTML** משלי (לא המקרא המובנה של Chart.js), כדי שיהיה מימין לשמאל ונגיש: לכל קטגוריה ריבוע צבע, שם, והערך (₪ או כמות) — כך שאין הסתמכות על צבע בלבד (DESIGN 2.1).
- רק קטגוריות שיש בהן הוצאות (PRD 4.5).
- Tooltip במעבר עכבר/נגיעה: שם הקטגוריה והערך.
- **צבעים:** 11 קטגוריות אבל בפלטה יש 6 צבעי הדגשה (Cyan, Aqua, Teal, Hot Pink, Magenta, Violet). כל קטגוריה מקבלת צבע **קבוע** (אותו צבע בכל מדד ובכל ביקור): 6 הצבעים של הפלטה, ואחריהם 5 גוונים בהירים/כהים שלהם. הבחנה נוספת: המקרא עם הערכים, וקו מפריד כהה בין פרוסות.

### 3.3 עמודות — "הוצאות לפי שנים / חודשים"
- תיבת בחירה **קיבוץ**: "לפי שנים" / "לפי חודשים" (ברירת מחדל: "לפי חודשים", כמו ב-Wireframe).
- בתצוגה החודשית: תיבת בחירה **שנה** מתוך השנים שיש בהן הוצאות, ברירת מחדל — השנה החדשה ביותר. בתצוגה השנתית תיבת השנה מוסתרת.
- ציר X: חודשים בקיצור ("ינו", "פבר", …, "דצמ") או שנים. ציר Y: ₪ או כמות, עם פורמט מתאים. Tooltip עם הערך המלא.
- עמודות בגרדיאנט Cyan→Violet (כמו ב-Mockup), פינות מעוגלות, רשת עדינה.
- **כיוון הציר:** ינואר משמאל ודצמבר מימין — כמו בשני ה-Wireframes וב-Mockup של הטלפון. (ה-Mockup של המחשב מציג את הסדר ההפוך; לפי כללי הסתירות, ה-Wireframes קובעים מבנה.)

### 3.4 מצבים
- **טוען:** "טוען נתונים…" · **כשל טעינה:** "לא הצלחנו לטעון את ההוצאות" + "נסו שוב" (כמו בשאר הדפים).
- **אין הוצאות בכלל:** במקום שני הגרפים — "עדיין אין הוצאות להצגה בדו"חות. אפשר להוסיף הוצאות ב[דף הבית]." (PRD Edge Cases).
- **שנה נבחרת בלי הוצאות** לא יכולה לקרות (רשימת השנים מכילה רק שנים עם הוצאות).

### 3.5 נגישות ו-RTL
- כל גרף עטוף ב-`figure` עם כותרת, ול-canvas יש `role="img"` ו-`aria-label` עם סיכום קצר (למשל "הוצאות לפי קטגוריות: מזון ₪ 249.90, …").
- טקסטים בעברית; מספרים וסכומים בכיוון LTR. גופן Heebo/Inter גם בתוך הגרף (תוויות צירים ו-Tooltip).

### 3.6 עצמאות מהפילטרים
- הדף טוען את ההוצאות בעצמו דרך `useExpenses()` ולא משתמש במצב של דף הפילטרים — לכן סינון שם לא משפיע כאן. (פילטרי הייצוא יתווספו ב-M5 ויהיו נפרדים מהגרפים.)

## 4. תלויות וקבצים

**להוסיף:** `chart.js`, `react-chartjs-2` (לפי ARCHITECTURE). רושמים רק את הרכיבים הנדרשים (ArcElement, BarElement, CategoryScale, LinearScale, Tooltip) כדי לשמור על גודל קטן.

## 5. בדיקות אוטומטיות
- **`aggregate`:** קטגוריות בלי הוצאות לא מופיעות; סכומים מדויקים באגורות (למשל 0.10+0.20 = 0.30 בדיוק, ו-3×33.33 = 99.99); כמות; שנים ריקות באמצע = 0; 12 חודשים לשנה עם אפסים; הוצאה ב-31/12 וב-01/01 נספרת בשנה הנכונה; מיון הקטגוריות.
- **ממשק:** מעבר מדד מעדכן את ערכי המקרא; מעבר "לפי שנים"/"לפי חודשים" ובחירת שנה משנים את התוויות; אין הוצאות → הודעה במקום גרפים; כשל טעינה → הודעת שגיאה. (ב-jsdom אין canvas, ולכן בבדיקות הממשק רכיב הגרף מוחלף ברכיב פשוט, ובודקים את הנתונים שמועברים אליו ואת המקרא.)
- `npm test` ו-`npm run build` עוברים.

## 6. סדר העבודה בבנייה
1. `aggregate.ts` + בדיקות.
2. התקנת Chart.js; `chartTheme.ts`.
3. `CategoryPie`, `PeriodBars`, `ReportsPage`, נתיב.
4. בדיקות ממשק.
5. בדיקה בדפדפן מול Development (עם ההוצאות הקיימות, שכוללות כמה שנים וקטגוריות): השוואת הערכים בגרפים ובמקרא לחישוב ידני מתוך `GET /api/expenses`; מעבר מדד; שנים/חודשים ובחירת שנה; סינון בדף הפילטרים לא משנה את הגרפים; מחשב (1280px) וטלפון (375px); רענון בתוך `/reports`; מצב "אין הוצאות" (בבדיקת ממשק — בלי למחוק את הנתונים שלך).
6. `npm test`, `npm run build`, סימון 🟡 ב-MILESTONES.md, סגירת השרת.
